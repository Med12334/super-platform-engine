# 🌍 Super-Platform Logistics Engine

An enterprise-grade microservices architecture designed to handle real-time routing, dispatching, and logistics telemetry for a multi-vendor platform.

## 🚀 Tech Stack
* **Frontend:** Next.js (React), Tailwind CSS, Real-Time Polling
* **Backend API Gateway:** Python, FastAPI, CORS Middleware
* **Database:** SQLite, SQLAlchemy ORM
* **Algorithmic Engine:** Custom Python AI Spatial Clustering & Efficiency Routing

## ⚙️ Core Features
1. **Live Telemetry Dashboard:** Consumes stateful backend API data to monitor active drivers and pending deliveries in real-time.
2. **Two-Way Data Mutation:** Interactive UI components trigger asynchronous `POST` requests to dynamically update the SQL database state.
3. **AI Routing Optimization:** Dedicated Python engine continuously recalculates system load and routing efficiency based on live supply-and-demand ratios.

> *Built to demonstrate full-stack proficiency, state management, and algorithmic integration.*
